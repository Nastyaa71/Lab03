1. тип int занимает 4 байта независимо от величины числа. 
2. при увеличении числа меняются байты, в которых записывается его значение. 
3. в используемом порядке little-endian младший байт записывается первым.

BitConverter.IsLittleEndian: True.
Число: 305419896.
Hex-представление: 0x12345678.
Байты: 78-56-34-12.
Порядок называется little-endian: сначала хранится младший байт числа, затем остальные. Поэтому порядок байтов отличается от привычной записи шестнадцатеричного числа 12 34 56 78.

Строка Привет
Количество символов: 6.
Количество байтов UTF-8: 12.
Байты: D0-9F-D1-80-D0-B8-D0-B2-D0-B5-D1-82.
в UTF-8 английские буквы обычно занимают по одному байту, а русские буквы - по два байта. поэтому количество символов и количество байтов может отличаться.
Английская A: 41.
Русская А: D0-90.
Это разные символы, хотя внешне они похожи. В UTF-8 они имеют разное байтовое представление. Английская буква занимает один байт, русская - два.

Строка Привет преобразуется в массив байтов с помощью Encoding.UTF8.GetBytes(), а затем восстанавливается с помощью Encoding.UTF8.GetString(). Исходная и восстановленная строки совпадают.
Число 123456789 преобразуется в байты с помощью BitConverter.GetBytes(), а затем восстанавливается методом BitConverter.ToInt32(). Исходное и восстановленное числа совпадают.
Для обратного преобразования текста нужно снова указать UTF-8, потому что программа должна знать, по каким правилам превратить последовательность байтов обратно в символы.


1.Байт — единица хранения данных, состоящая из 8 бит.

2.Тип int имеет фиксированный размер 32 бита, то есть 4 байта. Этого достаточно для хранения целых чисел в его диапазоне.

3.Метод преобразует значение числа в массив байтов, из которых оно состоит в памяти.

4.Это свойство показывает, используется ли порядок little-endian, при котором младший байт хранится первым.

5.Потому что привычная запись числа и порядок расположения его байтов в памяти — не одно и то же. Это зависит от порядка байтов системы.

6.Потому что в UTF-8 разные символы могут занимать разное количество байтов.

7.Преобразует строку в массив байтов по правилам кодировки UTF-8.

8.Чтобы преобразовать байты обратно в строку, используя те же правила UTF-8.

9.Потому что сами байты не содержат указания, что они означают. Значение зависит от того, как программа их интерпретирует.

10.Число хранится в виде бинарного значения фиксированного типа, а текст преобразуется в байты с помощью кодировки, например UTF-8.
Итоговый вывод
Числа и текст хранятся в памяти компьютера в виде последовательностей байтов. Тип int занимает четыре байта, а порядок их расположения зависит от архитектуры компьютера. Текст преобразуется в байты с помощью кодировки, например UTF-8, поэтому разные символы могут занимать разное количество байтов. Чтобы правильно восстановить данные, программа должна знать правила их представления. Например, байты 48 65 6C 6C 6F при интерпретации как текст UTF-8 означают слово Hello.
